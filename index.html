Career Summary

I am a cloud-native security engineer. I build systems that show what production workloads are actually doing, and that change how those workloads behave without restarting them. I started in vulnerability research, chaining container escapes and Windows privilege escalation bugs, and I still decide what to monitor based on how these environments break in practice.

Most of my work falls into three areas: automated security assessment of cloud accounts, kernel-level observability with eBPF, and runtime replacement of cryptographic implementations. All three had to run against production systems that could not be modified or restarted. I also worked on financial-sector audits and breach investigations, so I know what a finding needs to contain before an operations team will act on it.

My current research is on the infrastructure around cryptography rather than the algorithms themselves. In a cloud-native environment it is hard to tell which protocol versions and algorithms workloads actually negotiate, and changing them usually means rebuilding images and dropping live connections. Post-quantum migration makes both of those urgent, so I work on cryptographic agility and runtime visibility as infrastructure properties, whether the target is a Kubernetes cluster, a cloud account, or a 5G core.
